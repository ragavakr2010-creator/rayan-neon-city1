# Rayan: Neon City — Android Prototype

Chapter 1: The Signal

## What is included
- Android app project
- Landscape mobile layout
- Title screen
- Story intro
- Top-down open-world city prototype
- Touch joystick
- Action button
- Mission/objective system
- Modern + futuristic neon districts

## Build
Open this folder in Android Studio with an Android SDK installed.
Let Android Studio sync the Gradle project, then choose:
Build > Build APK(s)

The generated debug APK will normally be under:
app/build/outputs/apk/debug/app-debug.apk
